# Aircraft Management System

## 📌 About the Project

This is a C++ academic project developed to practice Object-Oriented Programming (OOP) concepts by modeling different types of aircraft and managing passenger information.

## ✈️ Features

* Display aircraft information, including nationality, model, and speed.
* Represent different aircraft types, including fighter aircraft and passenger aircraft.
* Store and display passenger information, including name, nationality, destination, and time.
* Count the number of passenger records created.

## 🛠️ Concepts Applied

* Classes and Objects
* Inheritance
* Encapsulation
* Abstraction
* Polymorphism
* Constructors
* Static Data Members and Member Functions
* Header (`.h`) and Source (`.cpp`) Files

## 💻 Technologies

* Programming Language: C++
* Development Environment: Visual Studio Code

## 🎯 Project Purpose

The purpose of this project is to strengthen my understanding of C++ and Object-Oriented Programming through practical application.
